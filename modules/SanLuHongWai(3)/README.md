# 方案(3)：260脉冲/圈、67mm轮径，A点停车使能距离10036mm

# MSPM0G3507 三路红外循迹

本工程以 `10_DC_MOTOR_PID_2` 为基础，保留原有双电机速度 PI 参数和编码器测速，只把八路灰度模块替换为三路数字红外循迹模块。

## 接线

| 三路模块 | MSPM0G3507 |
| --- | --- |
| VCC | 3.3V |
| GND | GND |
| L | PB23 |
| M | PB26 |
| R | PB27 |

L、M、R必须分别安装在车体左、中、右位置。模块实测为：黑线输出1、通道灯灭；白底输出0、通道灯亮。

## 电机

- M1：右轮，前进方向 `direction=1`
- M2：左轮，前进方向 `direction=2`
- 速度 PI 和编码器接口沿用基础工程

## 状态处理

| LMR | 行为 |
| --- | --- |
| 010 | 直行 |
| 110 | 轻微左转 |
| 100 | 较强左转 |
| 011 | 轻微右转 |
| 001 | 较强右转 |
| 000 | 未曾见线则停车；运行中丢线则按上次方向低速找线 |
| 111 | 停止线/大面积黑区，停车 |
| 101 | 异常或分叉状态，停车 |

向左修正不是“给左轮加速”，而是让右轮M1更快、左轮M2更慢，使差速底盘向左转。

## 可调参数

参数位于 `user_driver/line_follow.c`：

- `BASE_SPEED_MM_S`：直行速度
- `SOFT_STEER_MM_S`：轻微修正幅度
- `HARD_STEER_MM_S`：强修正幅度
- `LOST_SPEED_MM_S`、`LOST_STEER_MM_S`：丢线搜索速度与差速

## A点停车线识别

- 不再要求L、M、R在同一时刻全部检测到黑线。
- 编码器累计距离达到5200mm后才允许识别A点，避免起步时在A线停车。
- 使能后要求R先连续检测20ms，随后M在300ms内连续检测20ms。
- L不作为必要停车条件；如果三路恰好同时压线，也会立即确认A点。
- 识别成功后停车状态被锁存，传感器离开横线也不会重新启动。
- `A_STOP_FORWARD_OFFSET_MM`用于补偿传感器横排与车辆停车测试点之间的距离。
