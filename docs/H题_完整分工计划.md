### 1.2 摆杆机构

- PPR水管 25cm，外径2cm×壁厚0.34mm（4分管）
- 凹槽顶部切开，内壁光滑不打磨
- 左端铰链/合页固定，右端连接舵机控制角度
- 凹槽边贴刻度线（间距0.1cm），不贴槽内

**结构设计：**

```
        铰链(左端固定)
          ↓
  ╔══════════════════════════╗  ← 25cm PPR水管(顶部切开成凹槽)
  ║     ○ 钢球 φ1cm         ║
  ╚══════════════════════════╝
                               ↓
                         舵机(右端，控制摆杆俯仰角度)
```

**PID巡线伪代码：**

```
红外位置 = w0*0 + w1*1 + w2*2 + w3*3 + w4*4  // 加权平均
误差 = 红外位置 - 中心位置(2.0)
修正量 = Kp*误差 + Kd*(误差-上次误差)
左轮速 = 基础速度 + 修正量
右轮速 = 基础速度 - 修正量
```

#### 任务2：摆杆舵机PID控制

- [ ] 接收 K230 发来的钢球坐标 (x, y, w, h)
- [ ] 目标位置 vs 实际位置的PID计算
- [ ] PWM 控制舵机角度调整摆杆俯仰
- [ ] 静止测试：O→+5cm→-5cm (任务3)
- [ ] 行驶测试：±1cm误差 (任务4/5/6)

```
球坐标(mm) → 偏移量 = 目标位置 - 实际位置
舵机角度 = Kp*偏移量 + Kd*(偏移量变化率)
PWM输出 = 角度 → 脉宽 (500~2500μs → 0~180°)
```

### 3.3 关键代码框架

```c
// MSPM0 main.c
int main(void) {
    SYSCFG_DL_init();
    DL_IWDT_disable();
    
    st7789_init();        // SPI屏
    motor_init();         // 电机PWM
    servo_init();         // 舵机PWM
    infrared_init();      // 5路红外
    uart_init();          // 接收K230
    
    while(1) {
        // 1. 巡线
        int line_pos = infrared_read();
        float error = line_pos - CENTER;
        float motor_correction = line_pid(error);
        motor_set_speed(BASE_SPEED + motor_correction, 
                        BASE_SPEED - motor_correction);
        
        // 2. 球位置控制
        if (ball_data_updated) {
            float ball_error = ball_target - ball_current;
            float servo_angle = ball_pid(ball_error);
            servo_set(servo_angle);
        }
        
        // 3. 显示更新
        st7789_draw_string(0, 0, "Time: XXs", RED, BLACK);
        st7789_draw_string(0, 16, "Ball: XXmm", GREEN, BLACK);
        
        // 4. 停车检测
        if (infrared_detect_stop_line()) {
            motor_stop();
            break;
        }
    }
}
```

## 六、风险与预案

| 风险 | 概率 | 预案 |
|------|------|------|
| 红外巡线被强光干扰 | 中 | 加遮光罩，使用调制红外 |
| WiFi图传延迟过高 | 低 | 改用K230热点直连 |
| 钢球检测受光线影响 | 中 | 补光灯+多组数据训练 |
| 舵机响应速度不够 | 中 | 换数字舵机或丝杆步进 |
| ST7789V屏调不通 | 低 | 改用OLED或代码调试 |
| 电池续航不足 | 低 | 多备一组电池 |
