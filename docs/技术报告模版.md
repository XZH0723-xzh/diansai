## 摘要

本作品基于 **K230 视觉模块**与**MSPM0G3507 微控制器**，构建了一套智能视觉识别与运动控制系统。K230 端运行 YOLO11 目标检测模型，实时识别目标物体的位置与类别，通过 UART 协议将检测数据传输至 MSPM0G3507。MSPM0 端接收数据后，控制电机驱动模块实现目标的自动追踪与跟随，同时在 SPI 显示屏上实时显示检测框与标签信息。系统具有识别精度高、响应速度快、可扩展性强等特点。

**关键词：** K230；YOLO；目标检测；MSPM0G3507；运动控制；SPI显示

## 1. 系统方案

### 1.1 总体方案设计

系统由**视觉感知层**和**运动控制层**两部分组成：

```
┌─────────────────┐     UART      ┌─────────────────┐
│   K230 视觉模块   │ ───────────→ │  MSPM0G3507     │
│                  │              │                  │
│  · YOLO11 推理   │              │  · 协议解析      │
│  · LCD 实时预览   │              │  · 运动控制      │
│  · UART 数据发送  │              │  · SPI 屏显示    │
└─────────────────┘              └────────┬────────┘
                                          │
                                    ┌─────┴─────┐
                                    │  电机驱动   │
                                    │  + 底盘    │
                                    └───────────┘
```

### 1.2 方案论证

| 方案 | 核心器件 | 优势 | 劣势 | 选择 |
|------|---------|------|------|------|
| 方案一 | OpenMV + STM32 | 生态成熟 | 算力不足 | ❌ |
| 方案二 | K210 + Arduino | 成本低 | 精度低 | ❌ |
| **方案三** | **K230 + MSPM0G3507** | **算力强、外设丰富** | 开发难度中 | ✅ |

K230 内置 KPU（神经网络处理器），支持 YOLO11 模型实时推理，帧率可达 xx FPS。MSPM0G3507 具有丰富的定时器和 PWM 输出，适合电机精确控制。两芯片通过 UART 串行通信，协议简单可靠。

## 2. 理论分析与计算

### 2.1 目标检测算法分析

采用 YOLO11n 模型，输入分辨率 320×320，输出为目标的边界框坐标 $(x, y, w, h)$、类别标签和置信度。

- 帧率：xx FPS
- 检测精度：xx mAP
- 模型大小：xx KB

### 2.2 坐标映射计算

K230 输出检测框坐标 $(x_s, y_s, w_s, h_s)$ 在摄像头坐标系中，需映射到运动控制坐标系：

$$x_m = \frac{x_s}{W_s} \times W_m, \quad y_m = \frac{y_s}{H_s} \times H_m$$

其中 $W_s \times H_s$ 为摄像头分辨率，$W_m \times H_m$ 为运动空间范围。

### 2.3 运动控制算法

（PID 控制 / 位置环 / 速度环 分析）

$$u(t) = K_p e(t) + K_i \int e(t)dt + K_d \frac{de(t)}{dt}$$

## 3. 软件设计

### 3.1 K230 端软件流程

```
初始化 → PipeLine(摄像头+LCD) → 加载YOLO11模型 → 循环:
  ├── 采集摄像头帧
  ├── KPU推理
  ├── OSD绘制检测框
  ├── LCD显示
  └── UART发送($len,id,x,y,w,h,class#)
```

### 3.2 MSPM0 端软件流程

```
初始化 → UART接收中断 → 协议解析(Pto_Data_Parse) → 循环:
  ├── 提取 x,y,w,h
  ├── 计算运动偏移量
  ├── PID控制输出
  └── 驱动电机PWM + SPI屏显示
```

## 6. 总结与展望

### 6.1 工作总结

本作品实现了 K230 视觉识别 + MSPM0 运动控制的完整系统。主要完成了以下工作：

1. K230 端部署 YOLO11 目标检测模型，实现实时多目标检测
2. 设计并实现了自定义 UART 通信协议，确保数据传输可靠
3. MSPM0 端完成协议解析和电机控制算法
4. SPI 显示屏实时反馈检测结果与系统状态

### 6.2 不足与改进

1. 当前模型类别较少，可扩展多类别识别
2. 运动控制可引入更高级的路径规划算法
3. 可增加无线通信模块实现远程监控
